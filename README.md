# إعداد ملف .env في مشروع الواجهة

انسخ هذا المثال إلى ملف `.env` في نفس المجلد وعدّله حسب جهازك:

```
# عنوان سيرفر اللعبة (WebSocket)
VITE_WS_URL=localhost:3001

# (اختياري) رمز الحماية — اتركه فارغًا إن لم تُفعّل الحماية في السيرفر
VITE_WS_TOKEN=
```

ملاحظات:

- المتغير الصحيح هو `VITE_WS_URL` (وليس `VITE_WEBSOCKET_URL`).
- إذا فعّلت رمز الحماية في السيرفر (ملف `server.config.json` في مشروع السيرفر)،
  ضع **نفس الرمز** في `VITE_WS_TOKEN` هنا ثم أعد بناء المشروع.
